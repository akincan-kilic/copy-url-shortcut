Chrome already uses ⌘⇧C for Inspect, so it may not assign that shortcut automatically.

  1. Open your browser’s extension shortcut settings.
  2. Find Copy URL Shortcut.
  3. Assign ⌘⇧C.
  4. Return to browsing.

If the button does nothing, visit chrome://extensions/shortcuts

You’re set.

The shortcut is assigned. Copy a URL, glance at the confirmation, and that’s it.

This Manifest V3 extension reads the current tab URL only when you invoke it, copies it on your device, and never sends it anywhere.
